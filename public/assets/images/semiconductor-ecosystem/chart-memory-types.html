One DRAM cell, three packages: DIMM, GDDR, HBM

The memory cell is identical in all three. What changes is how far the dies sit from the processor and how many wires reach them, which is where all the bandwidth comes from.

Bus width64 bits per module32 bits per chip, ~384 bits total1,024 bits per stack, 8,192 across a B200
Bandwidth~50 GB/s per module~1.8 TB/s (RTX 5090)~1.2 TB/s per stack, ~8 TB/s per B200
Distance to processor~3-5 cm, through a socket~1-3 cm, soldered around the die~2-5 mm, on the interposer
Where it is usedservers, desktopsgaming and workstation GPUsAI accelerators

A fourth variant, LPDDR5X, sits between them: 16-bit channels soldered about a centimetre away, reaching ~0.5 TB/s across the 480 GB of an NVIDIA Grace superchip, and it is what phones, laptops and CPU superchips run on. HBM4 doubles the per-stack bus again to 2,048 bits. The cost of that width: HBM burns 3-4x the wafer area per bit of DDR5 (TSV keep-out zones plus a logic base die), and the eight stacks are ~45% of a B200's build cost.
